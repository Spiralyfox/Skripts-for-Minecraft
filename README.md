## English

### 📖 About

Welcome! This repository contains a collection of Skript scripts that I'm sharing with the community. Feel free to use, modify, and adapt these scripts to fit your server's needs.

### ⚖️ Terms of Use

- ✅ **You can**: Modify scripts, translate them, adapt them to your server

- ❌ **You cannot**: Claim intellectual property rights or resell these scripts
- 💡 **Remember**: These resources are provided to help you - please respect the terms

### 🔧 Installation

#### Prerequisites

Before using these scripts, you **must** install Skript and its required dependencies. Follow these steps:

1. Install **Skript** (core plugin)
2. Install the required addons listed below
3. Restart your server
4. Place the scripts in `/plugins/Skript/scripts/`
5. Use `/skript reload all` or restart again
