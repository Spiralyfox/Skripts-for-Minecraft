# 🕊️ Fly

---

## Français

### 🔹 Description
Ce Skript permet au joueur d’activer/désactiver le mode vol via la commande `/fly`.  
Il annule également les dégâts de chute tant que le vol est activé, et désactive le vol à la déconnexion.

### 🔹 Commande
| Commande | Effet |
|----------|-------|
| `/fly`  | Active ou désactive le mode vol |

### 🔹 Permissions
| Permission | Description |
|------------|-------------|
| `spiralyskript.fly.fly` | Autorise l’utilisation de la commande |

### 🔹 Options modifiables
| Option | Valeur par défaut | Description |
|--------|------------------|-------------|
| `prefix` | `&b[Server name] &8» &r` | Préfixe affiché dans les messages |
| `msg_fly_enable` | `&aVous pouvez maintenant voler.` | Message quand le vol est activé |
| `msg_fly_disable` | `&cLe mode de vol est désactivé.` | Message quand le vol est désactivé |
| `msg_no_fall` | `&ePas de dégâts de chute car le mode de vol est activé.` | Message quand les dégâts de chute sont annulés |

## English

### 🔹 Description
This Skript allows players to toggle fly mode using the `/fly` command.  
It also cancels fall damage while fly mode is enabled and disables fly mode on disconnect.

### 🔹 Commands
| Command | Effect |
|---------|--------|
| `/fly` | Toggle fly mode |

### 🔹 Permissions
| Permission | Description |
|------------|-------------|
| `spiralyskript.fly.fly` | Allows the use of the command |

### 🔹 Configurable options
| Option | Default value | Description |
|--------|---------------|-------------|
| `prefix` | `&b[Server name] &8» &r` | Prefix shown in messages |
| `msg_fly_enable` | `&aYou can now fly.` | Message when fly mode is enabled |
| `msg_fly_disable` | `&cFly mode is disabled.` | Message when fly mode is disabled |
| `msg_no_fall` | `&eNo fall damage because fly mode is enabled.` | Message when fall damage is cancelled |
