# 🧭 Back

---

## Français

### 🔹 Description
Ce Skript permet aux joueurs de revenir à leur dernier emplacement de mort via un GUI, avec un cooldown. Un staff peut utiliser `/backplayer <joueur>` pour se téléporter à la mort d’un joueur.

### 🔹 Commandes
| Commande | Effet |
|----------|-------|
| `/back` | Ouvre un GUI pour retourner à son dernier emplacement de mort |
| `/backplayer <joueur>` | Téléporte le staff à la dernière mort du joueur ciblé |

### 🔹 Permissions
| Permission | Description |
|------------|-------------|
| `spiralyskript.back.back` | Autorise l’utilisation de `/back` |
| `spiralyskript.back.bypass` | Bypass le cooldown de `/back` |
| `spiralyskript.back.backplayer` | Autorise l’utilisation de `/backplayer` |

### 🔹 Options modifiables
| Option | Valeur par défaut | Description |
|--------|------------------|-------------|
| `prefix` | `&b[Server name] &8» &r` | Préfixe affiché dans les messages |
| `gui_name` | `&9Retour à l'emplacement de mort` | Nom du GUI |
| `back_cooldown` | `240` | Cooldown de `/back` en secondes |
| `msg_no_death` | `Aucune mort récente` | Message affiché si aucune mort |
| `msg_death_notify` | `Vous pouvez utiliser /back...` | Message envoyé après la mort |
| `msg_tp_success` | `Vous avez été téléporté...` | Message de téléportation réussie |
| `msg_no_player` | `Vous devez spécifier...` | Message d’erreur si pas de joueur |
| `msg_no_death_player` | `Le joueur ...` | Message si le joueur n’a pas de mort |

## English

### 🔹 Description
This Skript allows players to return to their last death location via a GUI, with a cooldown. Staff can use `/backplayer <player>` to teleport to a player’s last death location.

### 🔹 Commands
| Command | Effect |
|---------|--------|
| `/back` | Opens a GUI to return to your last death location |
| `/backplayer <player>` | Teleports staff to the player’s last death location |

### 🔹 Permissions
| Permission | Description |
|------------|-------------|
| `spiralyskript.back.back` | Allows using `/back` |
| `spiralyskript.back.bypass` | Bypass the `/back` cooldown |
| `spiralyskript.back.backplayer` | Allows using `/backplayer` |

### 🔹 Configurable options
| Option | Default value | Description |
|--------|---------------|-------------|
| `prefix` | `&b[Server name] &8» &r` | Prefix shown in messages |
| `gui_name` | `&9Return to death location` | GUI name |
| `back_cooldown` | `240` | `/back` cooldown in seconds |
| `msg_no_death` | `No recent death` | Message shown if no death recorded |
| `msg_death_notify` | `You can use /back...` | Message sent after death |
| `msg_tp_success` | `You have been teleported...` | Success teleport message |
| `msg_no_player` | `You must specify...` | Error message if no player |
| `msg_no_death_player` | `Player ...` | Message if player has no death |
