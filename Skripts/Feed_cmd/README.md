# 🍗 Feed

---

## Français

### 🔹 Description
Ce Skript permet de remplir instantanément la faim d’un joueur via la commande `/feed`.

### 🔹 Commande
| Commande | Effet |
|----------|-------|
| `/feed`  | Remplit complètement la faim et la saturation |

### 🔹 Permissions
| Permission | Description |
|------------|-------------|
| `spiralyskript.feed.feed` | Autorise l’utilisation de la commande |

### 🔹 Options modifiables
| Option | Valeur par défaut | Description |
|--------|------------------|-------------|
| `prefix` | `&b[Server name] &8» &r` | Préfixe affiché dans les messages |
