# 🛠️ Repair

---

## Français

### 🔹 Description
Ce Skript permet de réparer l’outil tenu par le joueur via la commande `/repair`.

### 🔹 Commande
| Commande | Effet |
|----------|-------|
| `/repair` | Répare l’outil tenu par le joueur |

### 🔹 Permissions
| Permission | Description |
|------------|-------------|
| `spiralyskript.repair.repair` | Autorise l’utilisation de la commande |

### 🔹 Options modifiables
| Option | Valeur par défaut | Description |
|--------|------------------|-------------|
| `prefix` | `&b[Server name] &8» &r` | Préfixe affiché dans les messages |
