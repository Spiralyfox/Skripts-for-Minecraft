# ❄️ Freeze

---

## Français

### 🔹 Description
Ce Skript permet à un membre de la modération de geler ou dégeler un joueur via la commande `/freeze <joueur>`.

### 🔹 Commande
| Commande | Effet |
|----------|-------|
| `/freeze <joueur>` | Gèle ou dégel le joueur ciblé |

### 🔹 Permissions
| Permission | Description |
|------------|-------------|
| `spiralyskript.freeze.freeze` | Autorise l’utilisation de la commande |

### 🔹 Options modifiables
| Option | Valeur par défaut | Description |
|--------|------------------|-------------|
| `prefix` | `&b[Server name] &8» &r` | Préfixe affiché dans les messages |

### 🔹 Commands

|---------|--------|
| `/freeze <player>` | Freezes or unfreezes the targeted player |

### 🔹 Permissions
| Permission | Description |
|------------|-------------|
| `spiralyskript.freeze.freeze` | Allows the use of the command |

### 🔹 Configurable options
| Option | Default value | Description |
