# 🛡️ God Mode

---

## Français

### 🔹 Description
Ce Skript permet d’activer ou désactiver le mode god via la commande `/god`.  
Quand le mode est activé, le joueur ne subit aucun dégât.

### 🔹 Commande
| Commande | Effet |
|----------|-------|
| `/god`  | Active ou désactive le mode god |

### 🔹 Permissions
| Permission | Description |
|------------|-------------|
| `spiralyskript.god.god` | Autorise l’utilisation de la commande |

### 🔹 Options modifiables
| Option | Valeur par défaut | Description |
|--------|------------------|-------------|
| `prefix` | `&b[Server name] &8» &r` | Préfixe affiché dans les messages |
| `msg_god_on` | `&aLe mode &bgod &aest maintenant activé. Vous êtes invincible !` | Message quand le god mode est activé |
| `msg_god_off` | `&cLe mode &bgod &ca été désactivé. Vous n'êtes plus invincible.` | Message quand le god mode est désactivé |

## English

### 🔹 Description
This Skript allows players to toggle god mode using the `/god` command.  
When enabled, the player takes no damage.

### 🔹 Commands
| Command | Effect |
|---------|--------|
| `/god` | Toggle god mode |

### 🔹 Permissions
| Permission | Description |
|------------|-------------|
| `spiralyskript.god.god` | Allows the use of the command |

### 🔹 Configurable options
| Option | Default value | Description |
|--------|---------------|-------------|
| `prefix` | `&b[Server name] &8» &r` | Prefix shown in messages |
| `msg_god_on` | `&aGod mode is now enabled. You are invincible !` | Message when god mode is enabled |
| `msg_god_off` | `&cGod mode has been disabled. You are no longer invincible.` | Message when god mode is disabled |
