# 💤 Anti-AFK

---

## Français

### 🔹 Description
Ce Skript détecte les joueurs AFK et les kick automatiquement après un certain temps d’inactivité. Le joueur peut se mettre en AFK via `/afk`.

### 🔹 Commande
| Commande | Effet |
|----------|-------|
| `/afk` | Active / désactive le mode AFK |

### 🔹 Permissions
| Permission | Description |
|------------|-------------|
| `spiralyskript.antiafk.use` | Autorise l’utilisation de la commande `/afk` |
| `spiralyskript.antiafk.bypass` | Bypass l’anti-AFK (modération / staff) |

### 🔹 Options modifiables
| Option | Valeur par défaut | Description |
|--------|------------------|-------------|
| `prefix` | `&cAFK [Server name] &8» &r` | Préfixe affiché dans les messages |
| `timeafk` | `600` | Temps autorisé sans bouger avant le kick |
| `unsetafk` | message | Message envoyé quand le joueur quitte le mode AFK |
| `kickafk` | message | Message de kick quand le joueur est exclu |

## English

### 🔹 Description
This Skript detects AFK players and automatically kicks them after a set time of inactivity. Players can toggle AFK mode with `/afk`.

### 🔹 Commands
| Command | Effect |
|---------|--------|
| `/afk` | Toggles AFK mode |

### 🔹 Permissions
| Permission | Description |
|------------|-------------|
| `spiralyskript.antiafk.use` | Allows using `/afk` |
| `spiralyskript.antiafk.bypass` | Bypass the anti-AFK system (staff) |

### 🔹 Configurable options
| Option | Default value | Description |
|--------|---------------|-------------|
| `prefix` | `&cAFK [Server name] &8» &r` | Prefix shown in messages |
| `timeafk` | `600` | Allowed time without movement before kick |
| `unsetafk` | message | Message sent when AFK mode is disabled |
| `kickafk` | message | Kick message when the player is kicked |
