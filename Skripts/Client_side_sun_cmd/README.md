# ☀️ Sun

---

## Français

### 🔹 Description
Ce Skript permet de forcer le temps ensoleillé pour le joueur via la commande `/sun`.

### 🔹 Commande
| Commande | Effet |
|----------|-------|
| `/sun`   | Met le temps ensoleillé pour le joueur |

### 🔹 Permissions
| Permission | Description |
|------------|-------------|
| `spiralyskript.sun.sun` | Autorise l’utilisation de la commande |

### 🔹 Options modifiables
| Option | Valeur par défaut | Description |
|--------|------------------|-------------|
| `prefix` | `&b[Server name] &8» &r` | Préfixe affiché dans les messages |
